### 분담 원칙

| | |
| --- | --- |
| **경계를 코드에 적었다** | 각 파일 첫 줄에 `"단계 N · 무엇. 담당 X"` 형식으로 담당을 명시 |
| **같은 인터페이스를 유지했다** | 모델 단계마다 Gemini 대체품과 로컬 백엔드를 같은 모양으로 두어, 담당자가 서로의 코드를 몰라도 교체 가능 |
| **평가는 한 사람이 모았다** | 측정 기준이 사람마다 다르면 비교가 깨지므로, 평가 설계·도구·보고는 한 명이 전담 |
| **라벨링과 질문은 나눴다** | 편향 방지. 질문은 팀 외부, 라벨링은 담당 영상별로 분담 |
